# 订单编辑与审批

从「审批中心 → 订单编辑」进入 [订单编辑](http://localhost:9980/flowable/order)。此入口使用示例订单编号 `SO-DEMO-001`，每个账号独立编辑和保存自己的订单内容。首次进入会加载两条初始商品明细，合计 ¥3,280.00。

已有 Flowable 数据库需重新执行后端的 `sql/flowable/upgrade-workbench.sql`，创建订单保存表，再运行更新后的后端。

## 手动测试

1. 在「流程管理 → 流程模型」新建采购场景的流程，关联业务页面「测试订单详情」。
2. 添加开始事件、排他网关、财务审批、主管审批和结束事件。网关到财务审批的分支条件填写 `${amount > 2000}`，到主管审批的连线设为默认分支。为两个审批节点配置审批人，并连接至结束事件。
3. 在流程表单添加必填数字字段 `amount`（订单金额），保存并发布模型。
4. 在订单编辑页修改客户、交付信息或商品明细，核对小计和合计。点击「保存订单」，刷新页面确认内容已恢复。
5. 点击「提交审批」，选择已发布流程并核对预填金额。大于 ¥2,000.00 应进入财务审批，等于或小于 ¥2,000.00 应进入主管审批。如果订单有未保存的修改，页面会先保存订单再打开发起申请。
6. 在审批详情中核对客户、订单明细和金额。之后再保存新的订单内容，重新打开原审批详情，应依然显示原申请提交时的内容。
7. 使用对应的审批人处理申请。申请人可在订单页的「我的审批记录」查看状态及详情。
